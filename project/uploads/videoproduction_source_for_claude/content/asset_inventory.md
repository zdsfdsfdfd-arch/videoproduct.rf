## Рекомендации Claude

1. Использовать локальные файлы из /assets, если они присутствуют.
2. Не заменять их stock photography.
3. Не растягивать все изображения в одинаковые карточки.
4. Использовать разные crop/aspect ratios.
5. Использовать изображения как часть editorial compositions.
6. Для отсутствующих изображений не выдумывать людей или проекты.
7. Если asset не удалось скачать, сохранить его роль/описание и сделать компонент готовым для последующей подстановки.
